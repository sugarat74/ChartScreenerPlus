# Chartiko

Chartiko permite filtrar acciones mediante indicadores técnicos, obtener Candidates
y explorar gráficos interactivos. Incluye Saved Screeners y Watchlist para usuarios
registrados y un panel Admin de ingesta.

Sitio de producción: [www.chartiko.com](https://www.chartiko.com).

Stack: Laravel + engine Python + React/TypeScript en `frontend/`. Verificación local:
`.\init.ps1`. `alphapulse/` conserva el prototipo de referencia visual. El nombre del
repositorio y las rutas históricas del VPS son identificadores internos.

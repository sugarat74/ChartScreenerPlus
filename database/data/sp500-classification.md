# S&P 500 classification snapshot (2026-10-24)

`sp500.csv` keeps the original 503 symbols, names, sectors and exchanges from its 2026-09-29 snapshot. Its `industry` (GICS sub-industry) and `country` (headquarters country, ISO 3166-1 alpha-2) columns were joined by exact ticker from the dated source snapshot `sp500-classification-source.csv`. No constituent was added or removed by this update.

- Source: [datasets/s-and-p-500-companies `data/constituents.csv`](https://github.com/datasets/s-and-p-500-companies/blob/main/data/constituents.csv), downloaded 2026-10-24; source file SHA-256 `6886dbca4c4845f1900162541c07d2723b775494f110e8c3f0b9aa81a9dae826`.
- Origin: [Wikipedia's S&P 500 component table](https://en.wikipedia.org/wiki/List_of_S%26P_500_companies), columns `Symbol`, `GICS Sub-Industry`, `Headquarters Location`. The dataset package [declares ODC-PDDL-1.0](https://github.com/datasets/s-and-p-500-companies/blob/main/datapackage.json). This file records attribution and modifications; GICS names remain attributed data and their licensing should be revisited before any commercial redistribution beyond the current Screener display.
- Modifications: kept only symbol, sub-industry and headquarters location in the committed source snapshot; mapped sub-industry verbatim to `industry`; mapped the final headquarters location component to a country code only when it matched an explicit US state/DC name or one of Ireland (`IE`), United Kingdom (`GB`), Switzerland (`CH`), Bermuda (`BM`), Netherlands (`NL`) and Canada (`CA`). Numeric Wikipedia footnote suffixes such as `[2]` were stripped before matching. No name/exchange inference and no runtime network request.
- Join result: 500/503 existing tickers matched; `CTVA`, `PSKY` and `WBD` were absent from the newer source, so both new values are null. `XYZ` had headquarters location `none`, so its country is null while its sub-industry remains populated. The newer source also contained `SKYD`, `TWLO` and `VYLR`, which were intentionally not added to the existing Universe. Final coverage: 500 industries, 499 countries; country counts: US 475, IE 11, GB 5, CH 3, BM 2, NL 2, CA 1, null 4.

The seeder reads only `sp500.csv` and stays offline. A later constituent refresh must reconcile both snapshots by ticker and review source terms, changes and ambiguous locations again before overwriting the committed data.

## Pruebas y fuentes

- `.\init.ps1`: exit 0; Laravel 154 pruebas / 985 aserciones; frontend lint y build, 133 módulos; engine 47 pruebas (aviso deprecado Starlette/httpx existente). Revisión estática de Nginx confirma que `X-Robots-Tag` solo cubre rutas SPA de app y no modifica locations `/api` ni `/sanctum`; no se pudo ejecutar `nginx -t` en Windows.
- Preview local Vite: `/` 200 con portada, CTA y JSON-LD; `/robots.txt` 200 `text/plain`; `/sitemap.xml` 200 `text/xml` con la portada; `/screener`, `/admin`, `/portal` y ruta desconocida devuelven el fallback SPA 200. La URL del sitemap es absoluta y el XML contiene solo `/`.
- Producción consultada por HTTPS el 2026-10-04: home 200; robots/sitemap/rutas profundas y ruta inexistente devuelven el HTML SPA de 702 bytes, `text/html`. No se afirma que el cambio esté publicado.
- La inspección de código no encontró integración de GA, GTM, Search Console ni Bing Webmaster Tools en `frontend/`, `resources/` y `docs/`.
- Fuentes primarias consultadas el 2026-10-04: [Google JavaScript SEO](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics), [Google sitemaps](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap), [Google canonicalización](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls), [Google AI features](https://developers.google.com/search/docs/appearance/ai-features). Google describe rastreo/renderizado/indexación en fases; acepta links HTML `href`, títulos/descripciones y canonical, advierte sobre soft-404 de SPA y señala que sus funciones AI no requieren schema o archivos especiales.
- No se ejecutó Lighthouse, validación Rich Results, Search Console, prueba de indexación ni monitorización de citas.
